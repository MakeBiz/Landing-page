Questions and answers

Which VPS do we need for Bitrix24?

Cloud Bitrix24 needs no server. For on-premise Bitrix24 with 50 users a server with 4 vCPU, 8 GB RAM and an NVMe disk is usually enough, for hundreds of users more. We size the configuration for your users and load.

Are there servers in the UAE?

Yes, some providers on the list offer UAE locations, marked UAE in the card. If data must stay in the country, we start with them.

Do you resell servers?

No. You buy the server from the provider directly, on your own account, and pay them. We help you choose, deploy and configure the system and can take the server on support.

How much does server setup cost?

Work is AED 200 per hour or within a support package from AED 1,250 a month. We give an estimate in hours before we start.

Why are the links affiliate links?

MakeBiz may receive a reward from the provider, your price does not change. The list and order are the same as in our catalogue servercalc.com.
