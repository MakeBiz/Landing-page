Questions and answers

Which models do you install?

Open-weight models that run on your own server: families such as Llama, Qwen, Mistral and Gemma for chat and documents, Whisper-class models for speech. We pick the model for the task and the hardware and switch to better versions as they come out.

Do I need a GPU?

For a team, yes: models answer fast only on graphics cards with enough memory, from one 32 GB card in the smallest configuration to four 96 GB cards in the largest. The calculator picks the server class from A to F for your load.

What about updates?

Updates of models and software are part of support: with “Help” and “24×7 SLA” we install new versions after checking them on your tasks, with “Self” you get instructions and monitoring on request.

Can you install it on a rented server?

Yes. Rent a dedicated or GPU server from a partner (is*hosting, DataPacket) or from your own provider, and we install and set up the AI on it. In the calculator choose “Rent” to see the monthly cost.

How long does the launch take?

It depends on hardware delivery and on the number of tasks and integrations. On a server that is already available we start the installation right after the technical meeting. The exact schedule comes with the quote.

What is included in support?

Three options a month: “Self” $620 (monitoring on request), “Help” $1,480 (updates and assistance), “24×7 SLA” $3,090 (on-call team and response times).

How is the price calculated?

Server of the chosen class with assembly and test, installation $3,700, setup of each task and integrations; for “No downtime” a standby server is added. Services are shown as a range. Monthly costs are support and, if you rent, the rent. Prices as of November 2026, the exact quote follows a technical meeting.
